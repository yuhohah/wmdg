## Atualizar

1. Execute `npm run dev` e abra uma sessão isolada do navegador, sem carregar o progresso pessoal.
2. Inicie o culto. No painel T/F2, prepare os recursos e sistemas necessários para mostrar a cena; pause a produção para estabilizar os saldos.
3. Conclua ou dispense as apresentações dos cards. Use a navegação inferior para enquadrar o santuário ou a Gnose.
4. Para o duelo, prepare prontidão acima de 80%, desafie Anúbis e espere a procissão e a chegada. Capture com a roda completa e uma fenda visível.
5. Salve a captura diretamente, sem alterar a arte ou montar uma interface fictícia. Substitua o PNG correspondente, confira a legibilidade e atualize esta data.

As capturas do santuário/duelo usam viewport CSS de 1600 × 1000; a Gnose usa 1600 × 1280 para mostrar o card completo. O navegador pode normalizar a resolução do PNG. Os arquivos são referenciados pelo README e pelo GDD.
